# 🐍 Menu Interativo em Python

Projeto desenvolvido em **Python** para praticar lógica de programação, estruturas de controle e interação com o usuário por meio de um menu executado no terminal.

## 📌 Sobre o projeto

A aplicação apresenta opções ao usuário e executa diferentes ações de acordo com a escolha realizada.

O projeto foi criado como exercício prático para consolidar conceitos fundamentais de programação.

## 🛠️ Tecnologia utilizada

- Python 3

## 🧠 Conceitos praticados

- Variáveis
- Entrada e saída de dados
- Estruturas condicionais
- Estruturas de repetição
- Funções
- Validação de entradas
- Organização da lógica de execução
- Interação com o usuário pelo terminal

## 🚀 Como executar

### Pré-requisito

Ter o **Python 3** instalado.

### Executando o projeto

Clone o repositório:

```bash
git clone https://github.com/budack/Menu_interativo.git
```

Entre na pasta:

```bash
cd Menu_interativo
```

Execute o arquivo:

```bash
python "Menu Interativo .py"
```

## 🎯 Objetivo

O projeto tem como objetivo reforçar os fundamentos de lógica de programação por meio de uma aplicação simples e interativa.
